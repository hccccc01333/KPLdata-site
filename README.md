# KPL 数据中心 · 官网

KPL 赛事数据产品站点（纯静态）：赛程比分、战队 / 选手 / 英雄数据、BP 分析、逐局复盘、实时胜率与预测公开统计。

- 数据来源：腾讯 KPL 官方公开接口（赛程 / 对局 / 局内快照），为个人搭建的赛事数据产品，**非官方、与腾讯无关联**
- 覆盖：2019–2026 全部 33 个赛事 · 2,900+ 场比赛 · 11,000+ 局（含 BP、选手逐局数据、出装、回放视频链接）
- 实时链路：比赛日 1 秒粒度采集快照，实时页 30 秒刷新（胜率曲线 / 指标 / 趋势外推预测），逐局自动归档
- 页面：首页 / 赛程 / 战队 / 选手 / 英雄 / 组合 / BP / 预测 / 查询 / 对比 / 交手 / 比赛 / 对局 / 模拟器 / 数据说明

## 目录

```
*.html            15 个页面（纯静态）
assets/           样式 / 脚本 / 数据（assets/games/ 为逐局详情分片，按需加载）
build_*.py        数据生成脚本（读取本地赛事数据仓，见下）
DESIGN.md         站点设计规范（配色 / 字体 / 动效 / 实时链路标准）
```

数据由本地赛事数据仓（采集 + 模型）生成后推送本仓库；静态托管平台自动发布。
数据仅用于学习研究，请勿再分发。

## 发布

```bat
publish.bat "更新说明"    # 提交并推送，托管平台自动重新部署
```
